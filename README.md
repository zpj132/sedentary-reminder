# 久坐提醒 Sedentary Reminder

一款极简的 Android 久坐提醒应用。设定「久坐时长」与「活动时长」后，App 在后台自动循环计时：久坐到点提醒你起身活动，活动结束再提醒你回到工作，如此往复，无需任何手动干预。

## ✨ 功能特性

- **双时长可调**：久坐 5–240 分钟、活动 1–120 分钟，计时中修改在下一阶段生效
- **全自动循环**：久坐 ⇄ 活动 无限往复，锁屏、后台、重启手机都能继续
- **双通道触发**：前台服务进程内计时 + 系统精确闹钟（AlarmManager）互为备份，先到者触发、另一方自动跳过，不漏报也不重复
- **多方式提醒**：全屏弹窗、系统通知、响铃、震动，均可独立开关
- **纯本地运行**：无任何网络请求，不收集任何数据
- **极小体积**：约 46 KB，纯原生实现，零第三方依赖

## 📱 系统要求

- Android 8.0（API 26）及以上

## 🎯 使用场景

- 办公室久坐族：每工作 45 分钟，提醒起身活动 5 分钟
- 备考学习：用「学习 N 分钟 + 休息 M 分钟」的节奏管理时间
- 需要定时起身的人群：程序员、司机、电竞玩家、术后康复等

## 📖 使用方法

1. 从 [Releases](../../releases) 下载最新 APK 安装
2. 打开 App，设置「久坐时长」与「活动时长」
3. 点击「开始循环」——到点后自动弹窗 + 通知提醒，点「知道了」即进入下一阶段
4. 随时点「停止循环」结束

### 权限说明

| 权限 | 用途 |
|---|---|
| 通知 | 到点发出提醒（Android 13+ 需手动授权） |
| 精确闹钟 | 保证提醒准点触发 |
| 显示在其他应用上层 | 全屏弹窗提醒（可选，不授予则用通知横幅） |
| 自启动 / 后台运行 | 国产 ROM 需手动允许，见下方常见问题 |

## ❓ 常见问题

**到点没有提醒，打开 App 才收到？**

国产 ROM（MIUI / HyperOS / EMUI 等）默认拦截后台应用的自启动广播。请在 系统设置 → 应用管理 → 久坐提醒 中开启「**自启动**」，并将**省电策略设为无限制**。

**响铃没有声音？**

提醒音走「**闹钟音量**」通道（与媒体音量相互独立）：按音量键 → 点齿轮图标 → 调大闹钟音量；同时确认未开启勿扰模式。

**可以不装任何权限吗？**

可以，但提醒的可靠性会下降：通知权限影响提醒是否可见，自启动影响后台能否准点触发。建议至少授予这两项。

## 🔨 从源码构建

```bat
git clone https://github.com/zpj132/sedentary-reminder.git
cd sedentary-reminder
build.bat
```

构建脚本需要本机安装 JDK 17+ 与 Android SDK（Platform 34 + Build-Tools 36），路径写在 `build.bat` 开头，按需修改。构建产物为 `out\SedentaryReminder.apk`（已自动签名；`out\` 下的签名密钥请自行妥善保管，勿外传）。

## 🧱 工作原理（简述）

计时状态机（久坐 ⇄ 活动、轮次、下次触发时间）持久化于 SharedPreferences，进程被杀后可无损恢复。到点触发由 **AlarmManager 精确闹钟**与**前台服务内的计时器**双通道完成；提醒通过高优先级通知（可选全屏 Intent 弹窗）呈现，声音与震动按用户开关选择独立的通知渠道。
