# 久坐提醒（Android 原生 App）

久坐计时 → 弹窗/通知提醒 → 活动计时 → 自动回到久坐计时，无限循环。两个时长都可调。
用**系统精确闹钟（AlarmManager）**驱动，锁屏、熄屏、关掉 App 都会准时提醒，手机重启后自动恢复计时。

- 安装包：`out\SedentaryReminder.apk`（已复制到桌面：`久坐提醒.apk`）
- 系统要求：Android 8.0 及以上
- 体积：约 42 KB，无任何网络请求，数据只存在手机本地

## 一、安装（3 步）

1. **传到手机**：把 `久坐提醒.apk` 通过微信/QQ「文件传输助手」、数据线或网盘发到手机上。
2. **安装**：在手机上点开这个 APK。第一次会提示「不允许安装未知来源应用」，按提示允许
   （一般路径：设置 → 安全 → 安装未知应用 → 允许来源应用；不同品牌叫法略有差异）。
3. **给权限**：首次打开 App 后点「开始循环」，按弹窗允许两项权限：
   - **通知权限**（Android 13+）：提醒通过通知/弹窗出现所必需；
   - **闹钟和提醒**（部分手机会问）：保证到点准时触发。

## 二、使用

| 操作 | 说明 |
|---|---|
| 久坐时长 / 活动时长 | 按 − / + 调整（久坐 5–240 分钟，活动 1–120 分钟），计时中修改则**下一阶段生效** |
| 开始循环 / 停止循环 | 一键启停。循环自动进行：久坐到点 → 提醒 → 自动开始活动倒计时 → 活动到点 → 提醒 → 自动开始下一轮久坐…… |
| 弹窗提醒（默认开） | 到点在当前手机画面上直接弹出提醒卡片。首次开启会要求「显示在其他应用上层」权限，允许一次即可 |
| 提醒时响铃（默认关） | 用系统闹钟音量响铃；办公室建议保持关闭 |
| 提醒时震动（默认开） | 手机震动 3 次 |
| 弹窗上的「停止提醒循环」 | 不解锁 App 也能直接停止整个循环 |

提醒内容：
- 久坐到点：「该起来活动啦！已连续久坐 X 分钟，起来活动 Y 分钟吧」
- 活动到点：「活动结束，继续加油，马上开始第 N 轮」

## 三、想让提醒 100% 准时响？（小米/华为等国产手机必看）

v1.1 起本 App 带有**前台常驻服务 + 双通道触发**（系统闹钟 + App 内计时互为备份），可靠性已大幅提升。
但国产系统的省电机制仍可能拦截，首次使用请务必做一次：

1. **设置 → 应用设置 → 应用管理 → 久坐提醒**：
   - **自启动：开**（关键！不开的话系统会拦截闹钟广播，表现为「到点不提醒，打开 App 才收到」）
   - **省电策略 → 无限制**
2. 最近任务里长按卡片 → 点 🔒 锁定
3. v1.1 起打开 App 会**自动恢复提醒循环**；通知栏会有常驻的「久坐提醒循环运行中」（显示下次提醒时间）——**看到它 = 提醒准点有保障**

## 三-2、响了但没声音/没震动？

- 响铃走的是**「闹钟音量」**（不是媒体音量）：按音量键 → 点设置齿轮 → 把闹钟音量调大
- 检查是否开了**勿扰模式**（勿扰会静掉通知声）
- 震动有渠道震动 + 直接震动双保险；若手机处于「静音（完全静音）」模式，部分机型会压制震动

## 四、开发者说明

- 纯原生实现（无第三方依赖）：`MainActivity`（界面）+ `AlarmReceiver`（到点处理并自动安排下一次）
  + `BootReceiver`（开机恢复）+ `PopupActivity`（全屏弹窗卡片）。
- 状态（阶段/轮次/下次时间）全部持久化在 SharedPreferences，进程被杀后依然正确。
- 重新构建：电脑上装好 JDK 后双击或执行 `build.bat` 即可（SDK 位于 `..\android-tools\sdk`）。
- 签名密钥：`out\release.keystore`（口令 sedentary2026），**升级安装必须用同一个密钥重签**，请勿删除。
